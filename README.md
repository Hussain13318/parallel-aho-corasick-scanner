\# Parallel Multi-Pattern Signature Scanner (Aho-Corasick + OpenMP)



Course: Parallel and Distributed Computing (Theory)



\## Problem

Scan large data against thousands of signatures using the Aho-Corasick

algorithm, then parallelize the scan with OpenMP and measure the speedup.



\## Folder structure

\- src/ source code (serial, OpenMP, MPI)

\- data/ scripts to generate test signatures and files

\- results/ timing results and graphs

\- docs/ scope pack and reports
